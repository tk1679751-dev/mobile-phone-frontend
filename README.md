# MobileMart — Premium Mobile Marketplace

**Your next phone starts here.** 🛒📱

MobiMart is a modern mobile phone marketplace frontend built for buying, selling, and trading pre-owned tech.

## ✨ Features

- 🔥 Browse a curated catalog of pre-owned & new phones (iPhone, Samsung, Google, OnePlus, Xiaomi)
- 🏷️ Authentic brand logos & real device photos
- 💰 Sell your phone and get a free valuation quote
- 🛒 Cart & wishlist flows
- 🌗 Full **dark & light mode**
- ✅ Quality-check driven UI (badges, ratings, stock, specs)

## 🛠️ Tech Stack

- ⚛️ React + Vite
- 🎨 Tailwind CSS
- 🗺️ React Router
- 🎨 lucide-react (icons)
- 🧠 Context API (ShopContext for cart / wishlist / toasts)
